# Cursor plans

Plans created for this workspace are stored here so they live with the repo and can be versioned or shared.

- **Naming:** Use a short, descriptive name and `.plan.md` (e.g. `plan_json_sports_metrics_ux.plan.md`).
- **Frontmatter:** Plans can use YAML frontmatter with `name`, `overview`, `todos`, etc. for tooling.
- **Future plans:** When creating new plans, save them under `.cursor/plans/` in this workspace.
